# 픽셀 탐정단: 숨은 그림 찾기

브라우저에서 바로 실행되는 단일 페이지 픽셀 아트 숨은 그림 찾기 게임입니다. 외부 이미지, 프레임워크, API 없이 `index.html` 하나만으로 전체 게임이 동작합니다.

## 게임 구성

- 총 12개 스테이지
- 총 87개의 숨은 목표물
- 스테이지별 6~9개 목표와 점진적인 난이도 상승
- 제한 시간, 오답 시 3초 감점, 최대 5배 콤보
- 힌트 충전 및 목표 강조 효과
- 스테이지별 8비트 배경음 패턴과 효과음
- 최고 점수 로컬 저장
- 12단계 사건 진행도 표시
- 데스크톱·태블릿·모바일 반응형 UI

## 스테이지

1. 반딧불 마법 숲
2. 달빛 야시장
3. 해적단의 비밀 항구
4. 눈꽃 산장
5. 심해 연구소
6. 장난감 공장
7. 유령 도서관
8. 궤도 우주정거장
9. 황금 사막 유적
10. 별빛 놀이공원
11. 네온 옥상 도시
12. 시간의 성

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 됩니다.

```bash
git clone https://github.com/beerAndNacho/Hidinggame.git
cd Hidinggame
```

로컬 서버로 실행하려면 다음 명령을 사용할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 조작

- 마우스 또는 터치: 숨은 물건 선택
- `H`: 힌트 사용
- `M`: 소리 켜기/끄기
- 잘못된 위치 선택: 남은 시간 3초 감소
- 5초 안에 연속 발견: 콤보 배수 증가

## 기술 구성

- HTML5
- CSS3 반응형 UI와 픽셀 애니메이션
- Vanilla JavaScript
- 인라인 SVG 픽셀 아트
- Web Audio API 기반 배경음·효과음
- LocalStorage 기반 최고 점수 저장
