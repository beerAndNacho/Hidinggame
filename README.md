# 리얼 탐정단: 숨은 그림 찾기

브라우저에서 바로 실행되는 **30스테이지 사실적 장면 기반 숨은 그림 찾기 게임**입니다. 기존 캠페인·별점·오늘의 사건·힌트·레이더·저장 기능을 유지하면서 사건 현장을 고해상도 사진 중심으로 전환했습니다.

## 핵심 기능

- 5개 챕터, 30개 사건, 총 252개 목표물
- 스테이지마다 서로 다른 고해상도 사실적 배경
- 사진 위에 원래 목표물 좌표와 클릭 판정을 그대로 배치
- 시간·실수·힌트·레이더를 반영한 3별 평가
- 캠페인 진행, 사건 지도, 오늘의 사건, 최고 기록 자동 저장
- 사진 로딩 실패 시 내장 SVG 장면으로 자동 전환
- 각 장면에 사진가 출처 링크 표시
- 모바일·태블릿·데스크톱 반응형, PWA 지원

## 실행

정적 파일이므로 `index.html`을 열거나 정적 서버로 실행합니다.

```bash
python -m http.server 8080
```

검증:

```bash
npm test
```

## 배포

GitHub Pages와 Vercel에서 별도 빌드 없이 배포할 수 있습니다.

## 사진 출처

장면 사진은 각 스테이지 좌측 하단의 출처 링크에서 확인할 수 있습니다. 네트워크가 없거나 사진 로딩이 실패해도 내장 장면으로 계속 플레이할 수 있습니다.
