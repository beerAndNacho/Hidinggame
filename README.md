# 픽셀 탐정단: 숨은 그림 찾기 v2

브라우저에서 바로 실행되는 픽셀 아트 숨은 그림 찾기 게임입니다. 외부 이미지·프레임워크·API 없이 HTML, CSS, Vanilla JavaScript, 인라인 SVG만으로 동작합니다.

이번 v2에서는 기존 12개 사건을 유지하면서 **12개 신규 사건을 추가해 총 24개 스테이지, 200개의 숨은 목표물**로 확장했습니다. 단순 스테이지 나열이 아니라 캠페인 진행, 별 평가, 월드맵, 오늘의 사건 등 반복 플레이 구조도 함께 구현했습니다.

## 주요 기능

- 총 24개 픽셀 아트 스테이지
- 총 200개의 숨은 목표물
- 4개 챕터와 스테이지 잠금 해제
- 스테이지별 최고 점수·남은 시간·클리어 횟수 저장
- 시간, 실수, 힌트, 레이더 사용량에 따른 1~3별 평가
- 별 72개 수집 진행도
- 날짜에 따라 자동 선정되는 `오늘의 사건`
- 스테이지별 보너스 임무와 추가 점수
- 최대 6배 연속 발견 콤보
- 힌트와 전체 신호를 잠깐 보여 주는 레이더
- 오답 시 3초 감점 및 점수 차감
- 일시정지, 자동 일시정지, 배경음·효과음
- 기존 최고 점수 데이터 자동 이전
- 모바일·태블릿·데스크톱 반응형 UI
- PWA 매니페스트와 오프라인 캐시 지원

## 실행 방법

저장소를 내려받고 정적 서버를 실행합니다.

```bash
git clone https://github.com/beerAndNacho/Hidinggame.git
cd Hidinggame
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `index.html`을 직접 열어도 기본 게임은 동작하지만, 서비스 워커와 오프라인 캐시는 HTTP 환경에서 활성화됩니다.

## 조작

- 마우스 또는 터치: 숨은 물건 선택
- `H`: 힌트 사용
- `R`: 레이더 사용
- `P` 또는 `Esc`: 일시정지·복귀
- `M`: 소리 켜기·끄기
- 5초 안에 연속 발견: 콤보 증가
- 잘못된 위치 선택: 시간 3초 및 점수 감소

## 별 3개 조건

- **별 1개:** 제한 시간 안에 모든 목표 발견
- **별 2개:** 전체 시간의 20% 이상을 남기고 실수 3회 이하
- **별 3개:** 전체 시간의 40% 이상을 남기고 실수 1회 이하, 힌트 1회 이하, 레이더 미사용

## 저장 데이터

진행 정보는 브라우저 `localStorage`의 `pixelDetectiveSaveV2` 키에 저장됩니다.

- 잠금 해제된 스테이지
- 스테이지별 별·최고 점수·최고 잔여 시간·클리어 횟수
- 오늘의 사건 기록
- 업적
- 최고 누적 점수
- 음소거 설정

기존 버전의 `pixelHiddenBest` 최고 점수도 최초 실행 시 자동으로 가져옵니다.
